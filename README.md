# DROPLINE

**A portrait mobile pipe-connection puzzle game by Tonaroz Team.**

DROPLINE challenges players to rotate and connect pipe segments across a progression of **2,000 levels in five worlds**.

## Gameplay and customization

DROPLINE is designed for portrait Android devices. The game includes pipe skins and board backgrounds, a cosmetics shop, hints, and player progression. Temporary testing settings may make cosmetic items free and expose all worlds; these are development settings and may change before release.

## Development status

The repository currently contains project documentation and the public privacy page. The Unity source project must be added from the authorized development workspace. Do not treat this repository as containing a complete Unity project until the Unity `Assets`, `Packages`, and `ProjectSettings` directories have been published.

## Privacy and advertising

The DROPLINE Android application integrates Google AdMob for rewarded and interstitial advertising, and Google User Messaging Platform (UMP) for consent management. The data processed in a session depends on SDK behavior, app configuration, device settings, consent status, and regional requirements. See the [Privacy Policy](https://tonarozteam.github.io/DROPLINE/docs/privacy/) and [Privacy Choices](https://tonarozteam.github.io/DROPLINE/privacy-choices/).
